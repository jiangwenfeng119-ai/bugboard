# 建单前相似提示 — Design

日期：2026-11-25  
状态：待讨论，不改代码

路线已定为第一条：相似提示、分派写进详情、停留时间。这一份只写相似提示。分派写进详情、停留时间不在这里展开。

## 现在

新建报障在 [`NewBugPanel.tsx`](../../../src/app/projects/[id]/bugs/NewBugPanel.tsx) 提交到 `POST /api/projects/:id/bugs`。[`createBug`](../../../src/lib/services.ts) 直接插入 `status = 'pending'`，并写一条「创建报障」。提交前不查已有报障。

「问问项目助理」对照代码镜像和项目文档。判断是「建议报障」或「没有把握」时，可以写入标题、描述和优先级，不直接提交。它不查台账。

列表搜索 [`listBugs`](../../../src/lib/services.ts) 的 `q` 只匹配标题和报障编号，不搜正文。

走查审核里，草稿状态是 `draft` / `kept` / `discarded` / `merged`。`merged` 只并进同一次走查的上一条草稿。入库时，每条 `kept` 且还没有 `bug_id` 的草稿各调用一次 `createBug`，新单仍是待处理。

用户级测试提示词已经要求先用 `list_bugs` 的 `q` 搜标题，在待处理、修复中、待补充、待发布、待确认里看到相同现象就不再建。这是提示词，服务端不拦截。这一份不改那条提示词，也不给 `create_bug` 加拒绝。

进行中是：待处理、修复中、待补充、待产品经理确认、待发布、待确认。终态是：已确认、已认可、不属实。见 [`STATUS_FILTER_GROUPS`](../../../src/lib/types.ts)。

## 谁看见

能打开该项目的登录用户，在两处看见：

- 项目报障页的「新建报障」
- 该项目走查审核里，当前这条草稿

项目成员和账号管理员都能打开项目，因此都能看见。候选只来自这一个项目里他们本来就能打开的报障，不跨项目。

API Key 和 Agent 看不到这行提示。`create_bug` 和走查入库照旧成功。

## 什么时候出现

只查本项目、进行中的单。终态不进入候选，包括不属实。不属实仍可异议或撤回，但那是旧单详情上的动作，不从新建入口带出来。

匹配用现在的标题 / 编号包含关系，对着正在写的标题。不搜正文，不打分，不调用项目助理。

出现条件：

- 标题去掉空白后至少 4 个字
- 停手后再查，避免每敲一字请求一次
- 最多 3 条，按 `updated_at` 新的在前
- 有结果才显示。没有结果时不写「没有相似」
- 查询失败时不显示，也不挡住提交或入库

新建报障：放在标题下面。回答还在生成时，提示仍只跟标题走，不代替「整理并填入报障」。

走查审核：只挂在当前这条、状态还是 `draft` 或 `kept` 的草稿标题下。`discarded` 和 `merged` 不显示。本机 agent 还在整理时不查。

每一条显示优先级、报障编号、标题、状态。整行链到 `/bugs/{id}`。旁边一句：「这些单还在进行中。提交仍会新建一张。」

## 什么情况下不改状态

提示是只读的。下面这些都不写 `bugs.status`，不插入 `bug_status_events`，不叫醒，不改优先级，不把两张单关联起来。

| 动作 | 新单 | 旧单 | 草稿 |
|------|------|------|------|
| 出现候选 | 不创建 | 状态不变 | 不改留下或丢掉 |
| 点开旧单 | 不提交 | 只打开详情 | 不入库 |
| 点「提交报障」 | 新建，待处理，与现在的 `createBug` 相同 | 不合并、不标不属实、不写补充说明 | — |
| 走查留下后入库 | 每条留下的草稿仍各新建一张待处理 | 不改 | `kept` 仍入库。提示不把草稿改成 `merged` |
| 没有候选，或查询失败 | 提交按钮照常 | 无 | 入库照常 |

点开待产品经理确认的旧单，不算「可以做」或「不做」。点开待确认的旧单，不算确认或打回。

「提交报障」保持现在的文案，不改成必须先处理旧单。走查里的 M 仍是并进同一次走查的上一条草稿，不是并进已有报障。

服务端 `createBug` 和 `commitCaptureSession` 不因相似而拒绝。

## 不做什么

- 不给候选打置信度
- 不搜终态，不跨项目，不搜正文
- 不拦截网页提交、走查入库、`create_bug`
- 不改测试 Agent 提示词里已有的那条「搜到就不再建」
- 不在这一份里写分派结果进详情，也不写停留时间
